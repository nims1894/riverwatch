# Mobile Header Config Workflow

1. Open `scene-lab.html` and tune BOAT / FRONT WAVE / REAR WAVE / TREND / COMMON UI.
2. Open CONFIG tab.
3. Click **DOWNLOAD CONFIG.JS**.
4. In the main RiverWatch project, replace `js/mobile-header-config.js` with the downloaded file.
5. Commit/push. No manual editing of CSS/JS placement values is required.

`COPY CONFIG` copies the same JavaScript to the clipboard.
