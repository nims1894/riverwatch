# CAB-022 — Trim Deck Holdings Quantity

## Change
- Added each allocation group’s holding quantity beside its ticker in Trim Deck.
- Quantity is aggregated from Portfolio `quantity` / `shares`.
- Display uses English label `HOLDINGS`, thousands separators, and exactly one decimal place.

## Example
- `135287.34` → `135,287.3`
- `42613.5` → `42,613.5`
